Polymorphism:
_________________

 - if no inheritance , no polymorphism occur
 - it a pointer from parent , point to class object
 - parent hold the child , not visa versa , ex: Accountant acc1 = Employee(); // error , not accepted
 - ex: 
	class Employee{
		void view(){
			print("parent");
		}
	} 					// parent
	class Developer extends Employee{
		@override
		void view(){
			print("Developer");
		}
	} 					// child
	class Accountant extends Employee{
		@override
		void view(){
			print("Accountant");
		}
	} 					// child

	void main(){
		Employee emp1 = new Employee();
		emp1.view(); => scope/content => Employee, called view at Employee class
		//هيبص على الى بعد علامة يساوى ويشوف بينادى على انهى نسخه فى المثال هنا كان بينادى على نفسه كأب

		Employee emp2 = Developer();
		emp2.view(); 	=> what will be showen here is, what is inside the Employee class
			 	=> execute view(), will point after = sign , so will implement view function at Developer class if exist, else excute the view function at Employee class
	}
