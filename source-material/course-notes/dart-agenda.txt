	6 - Arrays:
		- at dart List<T> ,is the key syntax of array : ex: List<String> names = ["ahmed", "Toba"];
		- consist of:
			- Items  => what is values stored at the array
			- Length => the array items count
			- Index  => the position of the element in the array
		- initialize array
			- ex:
				import 'dart:io';
				void main(){
					List<String> arr = ['a', 'b', 'c', 'd'];
					print(arr);
					// how to display all items inside the array , one bye one
					for(int i = 0; i < arr.length; i++){
						stdout.write('${arr[i]}'); // a b c d
					}
				}
		- some commonly used methods at array:
			- add()			=> to add new item at the last position at the array
			- remove(object)	=> to delete the current item at the list
			- addAll(List)		=> to add more that one item at once at the list
			- ex:
				void main(){
					List arr = ['a', 'b', 'c'];
					print(arr);
					arr.add('d');
					print(arr);
					arr.remove('a');
					print(arr);
					arr.addAll(['e', 'f']);
					print(arr);
				}

 05 Encapsulation
	- restricting the direct access to some components of an object
	- like : make the variables of the class private, and create a setter function to assign value to it, and getter function to display the value from it
	-(Access Modifer: private) private variables: the class variables put as private , so the scope of it it the class it self,
		cannot access from outside the class
	- to make a variable private : put (_) underscore before it, like: _className = 'S5';
	- setter : special method to write at the private variable 		=> set
	- getter : special method to get the value from the private variable	=> get
	- ex:
		class Student(){
			// private attribute
			String _name;

			// setter
			set setName(String studentName){
				_name = studentName;
			}

			// getter
			String get getName{
				return _name;
			}
		}
