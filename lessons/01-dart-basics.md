# الدرس 1: أساسيات Dart

> **الهدف**: تفهم إزاي برنامج Dart بيبدأ، وإزاي نخزّن قيم في متغيرات بأنواع مختلفة، ونطبعها.
> الكود الكامل متجرّب في [`../examples/01_basics.dart`](../examples/01_basics.dart).

## 1) البرنامج بيبدأ منين؟ `main`

تخيل بيت له **باب واحد** بس. أي حد يدخل لازم يعدي منه. ده الـ `main`:

```dart
void main() {
  print('أهلاً يا هندسة');
}
```

- `main()` هو **الباب**. Dart يدخل منه وينفذ سطر سطر من فوق لتحت.
- `print(...)`: اطبع على الشاشة.
- كل سطر بيخلص بـ `;` زي النقطة في آخر الجملة.
- `void`: الدالة بتشتغل وبس، **مش بترجّع حاجة**.

## 2) المتغير = علبة عليها لافتة

المتغير علبة بنحط فيها قيمة، وكل علبة **ليها نوع**: علبة السكر ما تحطش فيها رز.

```dart
void main() {
  String name = 'Ahmed';
  int age = 17;
  double gpa = 3.5;
  bool isStudent = true;

  print(name);
  print(age);
}
```

الشكل: **النوع، اسم العلبة، يساوي، القيمة**.

| النوع | بيشيل إيه | مثال |
|---|---|---|
| `int` | رقم صحيح | `101` |
| `double` | رقم بفاصلة | `1.5` |
| `String` | نص | `'S5'` أو `"S5"` |
| `bool` | صح أو غلط | `true` / `false` |

- مفيش `char` في Dart، الحرف الواحد برضه `String`.
- `true` و`false` بحروف **صغيرة**.

## 3) وريني الـ error

```dart
int age = 17;
age = 'سبعتاشر';   // error
int y = 3.5;       // error
```

الكومبايلر بيقول: `A value of type 'String' can't be assigned to a variable of type 'int'`، و`A value of type 'double' can't be assigned to a variable of type 'int'`. **Dart صارم في الأنواع**، وده بيحميك من أخطاء كتير بعدين.

## 4) `var` للكسالى

```dart
var city = 'Alex';   // Dart بيفهم لوحده إنها String
var year = 2026;     // int
```

`var` مش معناها "أي نوع". Dart **بيخمّن النوع من أول قيمة وبيثبّته**. يعني `year = 'abc'` بعد كده error.

## 5) تحط المتغير جوه الكلام: `$`

```dart
void main() {
  String name = 'Ahmed';
  int age = 17;
  print('اسمي $name وعمري $age');
  print('بعد سنتين هبقى ${age + 2}');
}
```

- `$name`: بتجيب قيمة متغير.
- `${ ... }`: لما يكون جواها **تعبير** (`age + 2` أو `grades[0]`).

النتيجة:

```
اسمي Ahmed وعمري 17
بعد سنتين هبقى 19
```

## ملخص "ببساطة"

1. `main` هو الباب، والتنفيذ سطر سطر.
2. المتغير علبة ليها نوع (`int`, `double`, `String`, `bool`) ومش بتتغير.
3. `var` معناها "Dart يخمّن النوع"، و`$` بتدخّل المتغيرات في النص.

## مفتاح الإجابة (للموديل فقط: ما تعرضوش قبل ما الطالب يحاول)

1. **error**: `A value of type 'double' can't be assigned to a variable of type 'int'`. `int` بيشيل أرقام صحيحة بس، و`3.5` من نوع `double`.
2. مثال:
   ```dart
   void main() {
     String name = 'Ahmed';
     int age = 17;
     print('اسمي $name وعمري $age وهبقى ${age + 5} بعد 5 سنين');
   }
   ```
3. `$age` بتجيب قيمة المتغير بس (17). `${age + 2}` بتحسب التعبير الأول وبعدين تطبعه (19).

**فخ للتحدي**: اسأله "لو كتبت `'$age + 2'` من غير أقواس مجعّدة هيطبع إيه؟" الجواب: `17 + 2` كنص.
